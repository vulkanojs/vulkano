# ACCESSIBILITY.md

Accessibility convention for Vulkano Framework projects.

**Fully covered by `.claude/skills/vulkano-skills/vulkano-frontend-a11y/SKILL.md`** — images, navigation, forms, focus, color/contrast, structure. Invoke it instead of this file for implementation detail.

## Default rule

Every project meets these minimums unless the area's Accessibility column in `PROJECT.md` § Project requirements is off — that table is the only place that decides; this doc is a reference. If a task touches images, navigation, forms, or any interactive element and these minimums aren't met, fix them as part of the task — don't skip silently.
